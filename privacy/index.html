隐私政策

Loopfolio 没有账号、没有广告、没有分析 SDK。开发者没有服务器。

生效日期：2026 年 9 月 9 日 · 适用于 iOS 版本 0.3.0

学习进度和（可选的）API 密钥只留在你的设备上。只有你主动点「AI 讲解」时，当前单词才会经 HTTPS 发往你自己填写密钥的 DeepSeek。开发者收不到这些请求。

1. 开发者不收集的数据

不要求注册或登录，不接入广告、用户画像、跨 App 跟踪、第三方分析或远程崩溃报告。开发者不运营服务器，不会收到你的进度、密钥、姓名、邮箱、位置或设备标识符。

2. 留在设备上的内容

学习进度是一份本地 JSON，存在 App 的私有容器。DeepSeek API 密钥（若你填写）存在本机钥匙串，不进 iCloud 备份。卸载 App 会删除进度；在设置里删除密钥即从钥匙串移除。

3. 可选的网络请求

打字回合、词卡和词库查询不需要网络。仅当你保存了自己的 DeepSeek 密钥并点「AI 讲解」时，App 会把当前单词的词条（英文头词与词库里的中文释义）发往 DeepSeek，以生成讲解。费用由 DeepSeek 向你收取。该服务如何处理请求，见 DeepSeek 隐私政策。不填密钥就不会发出这类请求。

4. 词库

考试词表来自开源词库 ECDICT（MIT），随 App 打包在设备上，不从开发者服务器下载。

5. 儿童隐私

App 不面向儿童，也不明知收集儿童个人数据。

6. 政策变更

修改会更新本页并调整生效日期。重大变更会在 App Store 更新说明中提及。

English summary

Loopfolio has no account, ads, or analytics. The developer runs no server. Progress is a local file; an optional DeepSeek API key is stored in the Keychain. The typing loop works offline. Only if you save your own key and tap “AI explanation” does the current word leave the device, sent over HTTPS to DeepSeek. ECDICT word data ships inside the app.
